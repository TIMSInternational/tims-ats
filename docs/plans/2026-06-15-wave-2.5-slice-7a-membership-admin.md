# Wave 2.5 Slice 7a — Membership Admin Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build the admin surfaces that populate the access-control anchor tables — hrbp↔unit assignment (`UserBusinessUnit`), interview-panel evaluators (`InterviewEvaluator`), and calibration-committee members (`CalibrationMember`) — so the `unitIds`/`unitMemberIds`, `panelInterviewIds`, and committee anchors built in slices 1–4 can actually be filled by an admin.

**Architecture:** tRPC Router (Zod input) → inline service logic → `tenantDb` repository calls, gated by `permissionProcedure(module, action)` exactly like the rest of the wave. Three CRUD-over-anchor-table surfaces: assign/unassign/list for `UserBusinessUnit` (org module); add/remove evaluator on an EXISTING interview (interview module — `schedule` already seeds evaluators at creation, this adds post-hoc management); add/remove member on an EXISTING calibration session (ninebox module — `createCalibration` already seeds members at creation). Each mutation enforces org-isolation on BOTH the parent row and the target user, dedupes via the existing `@@unique` constraints (P2002 → friendly error), and the anchors immediately reflect changes (no cache — anchors are request-local). Then admin UI panels mirror the existing settings/admin component patterns.

**Tech Stack:** Next.js 15 App Router, tRPC, Prisma (`tenantDb`), Zod, Vitest, TypeScript strict, es/en i18n.

## Background (read before starting)

- **Anchor tables already exist + are consumed** (slice 1): `UserBusinessUnit` (`packages/db/prisma/schema/access.prisma:6-21` — `{id, organizationId, userId, businessUnitId, createdAt, updatedAt}`, `@@unique([userId, businessUnitId])`, FKs cascade); `InterviewEvaluator` (`packages/db/prisma/schema/interview.prisma:39-53` — `{id, interviewId, userId, role, status}`, `@@unique([interviewId, userId])`); `CalibrationMember` (`packages/db/prisma/schema/ninebox.prisma:41-54` — `{id, sessionId, userId, status}`, `@@unique([sessionId, userId])`). NO new migration needed.
- **Anchors that consume them** (`packages/api/src/access/anchors.ts`): `unitIds()`/`unitMemberIds()` read `UserBusinessUnit`; `panelInterviewIds()` reads `InterviewEvaluator`; committee calibration reads `CalibrationMember`. They are request-local (never cached), so a new assignment takes effect on the caller's next request — no invalidation needed.
- **Existing creation paths (do NOT duplicate)**: `interview/crud.ts:114 schedule` creates evaluators via `evaluators: { create: evaluatorIds.map(...) }` at scheduling; `ninebox.ts:254 createCalibration` creates members via `members: { create: input.memberIds.map(...) }` at session creation. This slice adds POST-HOC add/remove to existing parents.
- **Module→action gating** (`seed-access.ts`): hrbp-unit-assignment is an org-governance act → `permissionProcedure('organization', 'create'|'delete'|'read')` (hr_admin/super_admin hold org CRUD; this matches `createBusinessUnit`/`createTeam` in `organization.ts`). Evaluator management → `permissionProcedure('interview', 'update')` (mirrors `reschedule`/`cancel`). Calibration member management → `permissionProcedure('ninebox', 'update')` (mirrors `submitCalibrationVote`; NOTE the design — session CREATION needs `ninebox:create`, but managing members of an existing session is an `update`; align with whoever can manage the session — use `ninebox:update`, and additionally require the caller be the session creator OR hold org/company scope, mirroring `getCalibration`'s narrow-scope guard at `ninebox.ts:282-307`).
- **tenant client + isolation**: routers `import { tenantDb as db } from '@tims/db'`. Every query already runs under the RLS GUC, but per `.claude/rules/api-security.md` IDOR rule, EVERY mutation taking a parent id or user id MUST also `findFirst({ where: { id, organizationId } })`-verify both the parent (interview/session/businessUnit) AND the target user belong to `ctx.user.organizationId` before writing.
- **Validators** live in `packages/shared` (Zod), imported into routers (e.g. `createBusinessUnitSchema` at `organization.ts:8`). Add new input schemas there or inline in the router with bounded strings/uuids.
- **P2002 handling**: the `@@unique` constraints make double-assignment a Prisma P2002. Catch and map to `TRPCError({code:'CONFLICT'})` (pattern used in `engagement.submitSurveyResponse` per slice 2).
- **Test pattern**: static-source tripwires + behavioral where mockable, in `tests/access/`. Mirror `tests/access/scope-wiring-*.test.ts` (read router source, assert org-isolation + permissionProcedure) and the behavioral `vi.mock('@tims/db')` pattern from `tests/access/anchors.test.ts`. Vitest aliases in `vitest.config.ts`.
- **UI patterns**: settings pages under `apps/web/app/(admin)/settings/`; `components/modal.tsx` (title/onClose/children, esc+backdrop close); `useI18n()` for `t.*` keys (add to `apps/web/lib/i18n/{es,en}.json`); tRPC via `trpc.<router>.<proc>.useQuery()/useMutation()` + `utils.<router>.<proc>.invalidate()` on success + `toast()` on error. Existing `ApiKeysPanel` (`settings/integrations/integration-right-column.tsx:87-126`) is the read-list pattern; `settings/billing/page.tsx:62-100` is the mutation+toast pattern.

```typescript
  // ── hrbp ↔ business-unit assignment (Wave 2.5 slice 7a) ──────────────
  // Populates UserBusinessUnit, the anchor that unitIds()/unitMemberIds() read.
  // Org-governance act → organization:create/delete. IDOR: both the unit and the
  // target user are org-verified before writing.
  listUnitMembers: permissionProcedure('organization', 'read')
    .input(z.object({ businessUnitId: z.string().uuid() }))
    .query(async ({ ctx, input }) => {
      // Confirm the unit is in-org (NOT_FOUND otherwise — no cross-tenant probe).
      const unit = await db.businessUnit.findFirst({
        where: { id: input.businessUnitId, organizationId: ctx.user.organizationId },
        select: { id: true },
      });
      if (!unit) throw new TRPCError({ code: 'NOT_FOUND', message: 'Unidad de negocio no encontrada' });
      return db.userBusinessUnit.findMany({
        where: { businessUnitId: input.businessUnitId, organizationId: ctx.user.organizationId },
        select: {
          id: true,
          user: { select: { id: true, firstName: true, lastName: true, email: true, avatar: true } },
          createdAt: true,
        },
        orderBy: { createdAt: 'asc' },
      });
    }),

  assignUserToUnit: permissionProcedure('organization', 'create')
    .input(z.object({ userId: z.string().uuid(), businessUnitId: z.string().uuid() }))
    .mutation(async ({ ctx, input }) => {
      // Both the unit AND the user must belong to the caller's org (IDOR).
      const [unit, user] = await Promise.all([
        db.businessUnit.findFirst({
          where: { id: input.businessUnitId, organizationId: ctx.user.organizationId },
          select: { id: true },
        }),
        db.user.findFirst({
          where: { id: input.userId, organizationId: ctx.user.organizationId },
          select: { id: true },
        }),
      ]);
      if (!unit) throw new TRPCError({ code: 'NOT_FOUND', message: 'Unidad de negocio no encontrada' });
      if (!user) throw new TRPCError({ code: 'NOT_FOUND', message: 'Usuario no encontrado' });
      try {
        return await db.userBusinessUnit.create({
          data: {
            organizationId: ctx.user.organizationId,
            userId: input.userId,
            businessUnitId: input.businessUnitId,
          },
          select: { id: true },
        });
      } catch (err) {
        if (err && typeof err === 'object' && 'code' in err && (err as { code?: string }).code === 'P2002') {
          throw new TRPCError({ code: 'CONFLICT', message: 'El usuario ya esta asignado a esta unidad' });
        }
        throw err;
      }
    }),

  unassignUserFromUnit: permissionProcedure('organization', 'delete')
    .input(z.object({ userId: z.string().uuid(), businessUnitId: z.string().uuid() }))
    .mutation(async ({ ctx, input }) => {
      // deleteMany scoped by org + the unique pair: a non-org caller deletes 0 rows.
      const result = await db.userBusinessUnit.deleteMany({
        where: {
          organizationId: ctx.user.organizationId,
          userId: input.userId,
          businessUnitId: input.businessUnitId,
        },
      });
      if (result.count === 0) {
        throw new TRPCError({ code: 'NOT_FOUND', message: 'Asignacion no encontrada' });
      }
      return { success: true };
    }),
```

  // ── Evaluator (committee panel) management on an EXISTING interview ───
  // Populates InterviewEvaluator, the anchor panelInterviewIds() reads.
  addEvaluator: permissionProcedure('interview', 'update')
    .input(z.object({
      interviewId: z.string().uuid(),
      userId: z.string().uuid(),
      role: z.string().max(50).default('evaluator'),
    }))
    .mutation(async ({ ctx, input }) => {

          select: { id: true },
        }),
        db.user.findFirst({
          where: { id: input.userId, organizationId: ctx.user.organizationId },
          select: { id: true },
        }),
      ]);
      if (!interview) throw new TRPCError({ code: 'NOT_FOUND', message: 'Entrevista no encontrada' });
      if (!user) throw new TRPCError({ code: 'NOT_FOUND', message: 'Usuario no encontrado' });
      try {
        return await db.interviewEvaluator.create({
          data: { interviewId: input.interviewId, userId: input.userId, role: input.role },
          select: { id: true },
        });
      } catch (err) {
        if (err && typeof err === 'object' && 'code' in err && (err as { code?: string }).code === 'P2002') {
          throw new TRPCError({ code: 'CONFLICT', message: 'El evaluador ya esta asignado a esta entrevista' });
        }
        throw err;
      }
    }),

  removeEvaluator: permissionProcedure('interview', 'update')
    .input(z.object({ interviewId: z.string().uuid(), userId: z.string().uuid() }))
    .mutation(async ({ ctx, input }) => {
      // Org-scope the parent first so a non-org caller can't even target the row.
      const interview = await db.interview.findFirst({
        where: { id: input.interviewId, organizationId: ctx.user.organizationId },
        select: { id: true },
      });
      if (!interview) throw new TRPCError({ code: 'NOT_FOUND', message: 'Entrevista no encontrada' });
      const result = await db.interviewEvaluator.deleteMany({
        where: { interviewId: input.interviewId, userId: input.userId },
      });
      if (result.count === 0) throw new TRPCError({ code: 'NOT_FOUND', message: 'Evaluador no encontrado' });
      return { success: true };
    }),
